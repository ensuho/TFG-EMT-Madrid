# TFG-EMT-Madrid

Análisis de la eficiencia operativa del sistema de autobuses de EMT Madrid 
mediante datos abiertos.

## Descripción

Análisis empírico de la eficiencia operativa de las líneas 27, 34 y C1 del 
sistema de autobuses de EMT Madrid a partir de datos abiertos, mediante el 
cálculo de indicadores de frecuencia, regularidad y variabilidad del servicio.

## Requisitos

- Python 3.x
- Google Colab o Jupyter Notebook
- Librerías: pandas, numpy, matplotlib

## Fuentes de datos

Los datos utilizados en el análisis son de acceso público y pueden descargarse 
desde los siguientes portales:

- **Oferta real de autobuses (2025):**
  https://datos.emtmadrid.es/dataset/oferta-de-autobuses-diaria

- **Demanda diaria de viajeros (2025):**
  https://datos.emtmadrid.es/dataset/demanda-diaria-viajeros-autobus

- **Fichero de planificación (GTFS):**
  https://datos.emtmadrid.es/dataset/gtfs-de-emtmadrid

## Estructura del repositorio

- `TFG.ipynb` — Notebook principal con el código completo del análisis
- `resultados/` — Ficheros CSV con los indicadores calculados
- `graficos/` — Gráficos generados durante el análisis
